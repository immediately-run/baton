### What to build

The §14 row first, then the code, in `src/core/tickets.ts` beside B-194's.

1. **`GET /v1/repositories/{repository}/tickets/{ticket}`** (`ticket.show`, read; the repository
   reads' principals and a session): the ticket's `repo.tickets` row plus
   - `claim`: null, or `{claim_id, runner_id, hostname, session_name, leg, run_id, claimed_at,
     lease_ends_at, deadline_at, attempt, max_runs, next_backoff_until, session_url, log_dir}`
     (`session_url` only where R-BTN-113 passed it; `log_dir` text, R-BTN-128);
   - `attempts`: earlier attempts on the current leg, `[{run, runner_id, hostname, started_at,
     ended_at, end_reason, detail}]`;
   - `overrides: {expedite, hold: {set_by, reason, since} | null}`;
   - `conditions: [{condition_id, type}]` (open); `scope: [{id, kind, target, ref, at}]` (open
     scope findings, §12.9);
   - `parent`, `children` (ids); `resume` as `history` returns it (R-BTN-24); `web_url` (the
     ticket's page on its forge from `web_base`, R-BTN-92; null for a `git` forge);
   - `allowed: [<action id>]` — the target-dependent actions the caller may take on this ticket,
     computed by `authorize` with the caller as principal: today `ticket.unhold` (an approver on
     `approvers.policy`, R-BTN-186, or the delegated key that set the hold); a later
     target-dependent action joins the list in its own ticket.
   `not-found` for a ticket not in the repository, the same as for none.

### What not to do

- No body; no permission beyond `allowed`'s hint — `authorize` decides again on the call.
- No screen (B-210, B-222).

### Trust

- **The read** — Baton's rows; hostnames, reasons, refs, URIs and detail are untrusted text
  validated on write (§12.3), returned as text; `session_url` as the server passed it; `web_url`
  built from `web_base` only.
- **`allowed`** — computed by `authorize`; a drawing hint, not authority.

### Invariants

- **Positions are Baton's** (R-BTN-39); **filter fields only** (R-BTN-33); **log directories as
  text** (R-BTN-128); **session links only from `session_hosts`** (R-BTN-113).
- **An owner's session, its repositories** (R-BTN-155); **both hosts** (R-BTN-55).

### Tests

A scenario numbered at merge, on both hosts: `ticket.show` carries the claim, attempts,
overrides, conditions, scope findings, children, resume and `web_url`; `allowed` names
`ticket.unhold` for an approver's session and not for a non-approver's; a foreign id is
`not-found`.
