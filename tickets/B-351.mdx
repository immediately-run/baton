### Why

What sets a ticket's queued leg today, in the code:

- the finishing leg's `next`, checked by `decide()` (`src/runner/protocol.ts`);
- the sync's board post, folding git markers (`next_source` `marker` or `course`; `inferred` is accepted by `src/core/board.ts` but no station function produces it), written by `src/core/stations.ts`;
- the sync's `waiting_on: exhausted` (`src/defaults/course-pr.ts`), which `src/core/stations.ts` turns into a switch of the queued leg — the retry policy's `exhausted` leg that R-BTN-122 gives Baton is not built (B-11);
- a person leg's answer or expiry (`src/core/questions.ts`, `next_source: baton`);
- a new ticket's `start_leg`.

The owner's route and adopt are not built (R-BTN-83, R-BTN-39; B-120). Three things then filter the queued leg: the station function's readiness, a `not_before` from the sync or the result (R-BTN-89), and core's gates and blocks. R-BTN-205 replaces the choosing and the readiness with one course-owned function and one stored verdict.

### What to build

The children:

1. **B-352** — core: verdicts, selection wants, binding, the conditions, `ctx`, the routes and the data model.
2. **B-353** — the runner: running a selector, the default selector, chaining, re-verification, results without `next`.
3. **B-354** — host matching: a verdict's `host` against runners' declared dimensions.
4. **B-355** — seeing why: `baton ticket why`, `--replay`, the dashboard and the board.
5. **B-356** — the standard courses' selectors, and removing readiness, the holder's `next`, `baton.missing-next` and the retired `next_source` values.
6. **B-357** — measuring the selector's budget.

### Trust

- **A verdict is a claim**, from a holder's runner or a want's lessee. It can steer which leg is queued, never pass a gate: nothing that protects work moves from `gatesFor` into a selector.
- **A non-holder may post one** — any runner granted on the repository with the course declared, under `protected` only the policy's trusted runner class (R-BTN-182). Each verdict is bound to the want and the `ctx` digest it answers, and only the first valid one counts.
- **Denial of service** by a false `wait` or `attention` is visible and bounded: `until` at most 400 days, `baton.stalled` after the stalled time, `baton.selection-attention` at once, and the owner's route over either.
- **`select.mjs`** is a control path (R-BTN-184), run only through a runner's executor.

### Invariants

- **Core runs no repository code** ([R-BTN-133](../spec/BATON_SPEC/08-runners.md#sec-8-4)).
- **Baton holds every position** ([R-BTN-39](../spec/BATON_SPEC/01-what-baton-is.md#sec-1)): no snapshot sets one, and a verdict only queues a leg leaving Baton's station.
- **Gates are the only refusal** (§7.2).
- **Filter fields only, with one stated exception** ([R-BTN-33](../spec/BATON_SPEC/01-what-baton-is.md#sec-1)): a verdict's reasons, at most 128 characters each, shown as text.
- **One clock** ([R-BTN-32](../spec/BATON_SPEC/02-deployments.md#sec-2-1)).
