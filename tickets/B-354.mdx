### Why

The owner, 2026-11-26: "we should not start a leg requiring a sandbox with more memory than what the host can allocate." A verdict's `host` says what a runner must have; core matches it at the offer.

### What to build

1. **Heartbeat dimensions:** a runner declares numeric `host` dimensions (`memory_mb` first), validated in `src/core/validate.ts`.
2. **Matching at the offer, the claim and the starting `advance`:** `host.capabilities` by name as R-BTN-174 matches capabilities; each numeric dimension by "declared at least asked", a runner that declares no value for a dimension failing any requirement on it. Rule 1 refuses a runner that does not meet it, at claim and at advance.
3. **Capacity versus impossibility:** a leg no live runner meets waits for capacity, shown with the largest value live runners declare; one no registered runner granted on the repository meets raises `baton.selection-attention`, which closes when a runner that meets it registers or a later verdict replaces it.
4. **`fleet` totals** for `ctx`: per dimension and per capability, live and registered counts at or above each value — never a runner's identity.
5. **The course file's leg `host`**, read by the default selector.

### Trust

- **New input:** a runner's declared dimensions, its own statement, unchecked, as its capabilities are (R-BTN-66): a runner that overstates is only offered legs it cannot finish.
- **No exposure:** `fleet` carries totals only.

### Invariants

- **Capabilities are the runner's statement** ([R-BTN-174](../spec/BATON_SPEC/05-courses.md#sec-5-9)): no new check of a declaration.
- **Filter fields only** ([R-BTN-33](../spec/BATON_SPEC/01-what-baton-is.md#sec-1)): a dimension is a number.

### Tests

New S-BTN scenarios, numbered with `node cli/baton.mjs tickets next scenario`: `host.memory_mb` above every live runner's but within a registered one's waits for capacity; above every registered runner's raises `baton.selection-attention`; a runner declaring enough is offered the leg.

### Exit criteria

- [ ] `host` matched at the offer on both hosts; capacity and impossibility told apart and shown.
- [ ] The scenarios pass; `npm test`, `npm run typecheck` and `npm run check:spec` green; merged under the review gate.
