**Brief:** B-105's ticket, item 7: "Out of scope: core's existing `model_providers`, `peak_schedules`
and `provider_suspensions` tables are not read by route choices. File a ticket to retire them once
this lands." §6.10 (R-BTN-176) forms its atoms from the ontology, `external_resources` and
readings; nothing in the route-choice stratum reads these tables.

**What still touches them today** (surveyed at B-105's merge):

- `model_providers`, `peak_schedules` — written by the board `providers` sync and validated by
  `board.ts`; read back only for the board view. Nothing else.
- `provider_suspensions` — the worker API's set/lift/list endpoints and the alarm's start/end
  logging (`workerApi.ts`); the live ones read for the board view.

### What to build

1. **Decide, per surface**, whether §6.10 replaces it — a suspension becoming an `"unavailable"`
   route-choice state reading, a peak schedule becoming a guard over `now` — or it still earns its
   keep. What the spec does not settle, the owner does.
2. **Retire what goes**: the tables (migrations are append-only — a new numbered migration drops
   them), the sync fields, the endpoints, the dashboard rows, and their tests.
3. **Spec**: amend or retire the rows that name a retired surface, and their §15 scenarios.

### Tests

- The next free S-BTN numbers: a board sync without `providers` accepted; each retired endpoint
  answering 404; the drop migration leaving no row the core reads.

### Exit criteria

- [ ] no code path reads or writes a table this ticket retires; `npm test` and
      `npm run typecheck` green
- [ ] the spec names no retired surface

## Status

- 2026-11-02: the spec restructure's part 4 (B-166): route choices are gone (R-BTN-176 retired; B-167); the tables this ticket retires are read by nothing in core either way, so its plan stands, citing §6.10 and R-BTN-76 in place of R-BTN-176.
- 2026-11-08: implemented (PR #196) — migration 0036 drops the tables and the FK children forced with them; the sync's `providers`/`prices` and the heartbeat's advisory fields ride the accept-and-ignore window; the suspension endpoints answer 404; S-BTN-203 verifies it. B-107's wider retirement (PR #149, open) overlaps: whichever lands first, the other trims.
