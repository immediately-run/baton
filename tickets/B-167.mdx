### What to build

1. **Core.** Delete `src/core/ontology.ts`, `src/core/ontologies.ts` and `src/core/routes.ts`
   and every caller: the board post's `ontology` field and the course entries' `route_choices`
   (ignored and logged `deprecated-field` while the history's Migrations entry "part 4's retired
   fields" lasts, then refused, R-BTN-51, §4.4), `baton.ontology-refused`, `baton.ontology-limit`,
   derived sets and their alarm cycle, `not-derived` / `not-derivable`, the advance answer's
   `advice`, the `taken` field of an advance and an end, `advice-overridden` from a `taken`,
   `taken-invalid`, and reported `dead` holdings. Rule 4 (`gatesFor`, `src/core/gates.ts`) checks
   `capabilitiesOf(…) ⊆ declared ∩ grant` by name; `fleet_capabilities` counts declarations
   alone. A new numbered migration drops `ontologies`, `runner_derived`,
   `runner_derived_inputs`, `route_last` and `claim_legs.route_choices_json` / `taken_json`
   (never edit `0025_ontology.sql` or `0027_route_choices.sql`).
2. **The vendored library.** If `isEligible` (R-BTN-37) takes derived capabilities, change it in
   docs first, then `npm run vendor`.
3. **Course code and the CLI.** Delete `src/defaults/ontologyMerge.ts`, `ontology-asp.ts`,
   `ontology-asp-grammar.ts`, `src/defaults/ontology/` and the sync's merge; `repo init` stops
   scaffolding `.baton/ontology.json`. The runner stops writing `BATON_ADVICE` and creating
   `BATON_TAKEN` (R-BTN-144). The standard courses' `agent_command` wrappers and leg
   instructions (`src/defaults/courses/create-pr/implement.md`, `review.md`) choose their models
   from the repository's configuration (R-BTN-131, §6.10). This repository's own
   `.baton/baton.json` `route_choices` and `.baton/ontology.json` go; a runner that
   wants `capability:code-generation-llm` declares it with a check (R-BTN-121).
4. **Tests.** Delete `test/unit/ontology.test.ts`, `ontology-conformance.test.ts`,
   `routes.test.ts`, `test/fixtures/ontology/`, `test/integration/S-BTN-139.ontology.test.ts`,
   `S-BTN-147.route-choices.test.ts` and `S-BTN-147.runner-half.test.ts`, the `clingo-wasm`
   devDependency, and the retired ids in `test/unit/cli.test.ts` and `schema.test.ts`; then
   remove `S-BTN-139` and `S-BTN-147` from `RETIRED_TESTS_ALLOWED` in
   `scripts/check-spec.mjs`.
5. **The model.** `model/README.md` and `model/baton.qnt` stop citing derived capabilities and
   R-BTN-175 to R-BTN-177; the model receives a runner's declared, granted capabilities
   (R-BTN-68). A change to what the model checks carries a report.
6. **Pages that teach the built code.** README's code map, `docs/runbooks/register-baton.mdx`
   (its ontology and route-choice paragraph) and `docs/standard-courses.mdx` follow the code.
