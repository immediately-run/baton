**Brief:** the owner, 2026-11-01, on the whole-spec review they commissioned ("assess it for …
can any vocabulary, core concepts or actors be simplified … is the user experience intuitive …
are the security guarantees … truly guaranteed and … do they matter"), asked for its findings
to be filed as tickets. Source: `docs/review/spec-simplification-review-2026-11-01.mdx`.
The review's claims are a reviewer's, checked against the spec where they cite it; this ticket
verifies each against the text before changing anything.

### Why

Review finding 3 and section 1.1, candidate by candidate:
- git courier → `runner` the cooperative deliverer, `trusted-runner` the protected one (today
  a one-machine user with `--bind-conditions` must run a courier or notifications never leave);
- fact reader → the sync, under `protected` restricted to `sync-key`/`ci-identity`;
- protection checker → a mode of the merge runner;
- check-runner → a grant role; instrument → a `service:` key;
- dispatch courier → delete (it guards reach 0 only; see B-160);
- mirror, shadow mode, legacy runners, adoption requests, cutover → an adoption appendix that
  ends when docs retires its mirror.

### Decided (the owner)

**Rulings of 2026-11-01** (the owner, answering each question in the session that continued
immediately-run/baton#150; the restructure, B-166, writes them into the spec):

- Couriers merge into runners ("Couriers into runners"); the dispatch courier is dropped ("Drop
  it", with B-160). Kept as they are: the fact reader, the protection checker, check-runners,
  instruments, and the mirror and adoption machinery.

### What to build

1. **A spec PR first**, under the babysit skill's *Spec PRs*: two fresh reviewers, the impact list,
   every rule restating the same fact changed with it.
2. For each candidate, the PR states the merge or removal and what (if anything) it loses.
3. Tickets that build the removed actors (B-140's fact reader, B-152's dispatch courier, the
   protection checker) are rewritten or superseded with a map, per the babysit skill.
