**Brief:** the Baton project.
**Spec:** `spec/BATON_SPEC.md` §1 (R-BTN-50, the boundary test; the what-moves table is in
`spec/BATON_SPEC_HISTORY.md`), §2.1 R-BTN-37 (the vendored set ends), §5.6 R-BTN-60 and R-BTN-67
(owner and required bars in the gate), §6.6 rule 8, §15 S-BTN-28, -33, -39
**Depends on:** R3-1232, R3-1233

### Requires

- none — unit and integration tests in baton, and the vendoring script.

### Why

Core still holds `roadmap-pr` knowledge built before the 2026-10-14 amendment: rule 8 as
`qualifyingPair` over reviewer tables, provider tables and their endpoints, the
review-capacity hold, fixed step kinds, and docs' functions vendored into the Worker. Each
ties a course change to a Baton deploy. Tier: judgement — removals behind a test.

### What to build

1. Rule 8 as the generic tags gate: the ticket's posted bars per leg, joined by owner bars in
   force (claim-only bars skipped at advances), refused `barred-tag`; required bars hold a leg
   `waiting` on `policy` and refuse an advance into it.
2. Drop the provider, usage, suspension, reviewer and matrix tables and endpoints, the
   `review-capacity` hold and `awaiting-review-capacity`; step kinds from each course's
   registry entry.
3. End the vendored set: gates, default order and merge live in `src/core/`; `src/shared/`
   keeps nothing course-specific, and `npm run vendor` and its manifest go once nothing
   needs them.
4. The boundary test over all of `src/` with its shrinking exceptions list; the toy course
   `chore` (stations, a `redo` loop, no hooks) in `test/fixtures/`.

### Architecture — the decisions, named

- **Core compares tag strings and leg names, never meanings**; the boundary test's word list
  is BATON_SPEC §1's.
- **Owner and required bars are read from SQLite at every gate**, never from the board.
- **Do not**: keep a compatibility shim that reads the old reviewer tables; let the toy course
  share a fixture with `roadmap-pr`.

### Tests

- Integration: S-BTN-28 (the toy course runs the generic scenarios), S-BTN-33 (tags gate),
  S-BTN-39 (limits agents cannot change — the gate half).
- `test/unit/boundary.test.ts`.

### Exit criteria

- [ ] S-BTN-28, -33 and -39 pass; S-BTN-1…16 still pass
- [ ] `test/unit/boundary.test.ts` passes with an exceptions list no longer than before
- [ ] `git grep -n "qualifyingPair\|reviewer_agents\|provider_suspensions" src/` returns nothing
- [ ] `npm run typecheck` green
