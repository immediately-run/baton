**Brief:** continues R3-1257 (split 2026-10-19). The owner, 2026-10-15: legs that read each other's outputs need those outputs named, typed and found again; failures should name the producer; a past run should be re-runnable.
**Spec:** `spec/BATON_SPEC.md` §5.5 R-BTN-82 (outputs are R-BTN-108's envelopes, checked by its one validator), §9.8 R-BTN-84 (`baton leg replay`), §7.3 R-BTN-163 (`baton.contract`), §5.2 R-BTN-69 (a leg's `version`, `inputs`, `outputs`, `replay_safe`), §9.7 and §7.4 R-BTN-122 (`cannot-finish:contract-input` and `-output`), §8.3 R-BTN-72 (`ctx.inputs`, `close`), §13 (`leg_outputs`, `leg_run_inputs`, `run_inputs_by_ticket`, `repositories.artifact_buckets`), §12.3 (URIs and markers); §15 S-BTN-48, G-BTN-74.
**Depends on:** B-3. Under R-BTN-82 (§5.5) an output is an envelope naming `id@version`, given by pointer or inline, checked by one shared validator. B-3 builds the envelope and the validator. Building the earlier pointer-only contracts first would build the check twice.

### Requires

- none — every case runs in the integration harness with fixture course files and stub leg scripts, and a local git server for `git:` inputs.

### What to build

1. A course file's leg `version`, `inputs`, `outputs` and `replay_safe`, checked on acceptance (R-BTN-69).
2. URI validation (R-BTN-82, §12.3: the repository allowlist, `artifact_buckets`, the marker encoding, digests).
3. Inputs resolved at the advance that starts a leg. `input-missing`/`input-version` stored as `waiting` before the leg is offered. A foreign marker's outputs are never resolved.
4. `baton runner start` validates inputs before and outputs after the script, failing the leg `cannot-finish:contract-input` (held `non-retryable:contract-input`, raising `baton.contract`) or `contract-output` (a failed attempt). Landing before B-56, `baton.contract` is raised through R3-1257's Baton-raised decision path, which B-56 converts to the `suspend` core condition. The closing marker is written only from a validated result. `ctx.inputs` is set.
5. `inputs`/`outputs` history rows (R-BTN-81, built by R3-1257).
6. `baton leg replay [--run n] [--against sha]` with write credentials withheld; `replay_safe: false` refused.
7. `baton course test`'s dataflow and version checks.

### Tests

- Integration, both hosts: S-BTN-48.
- Unit: `contracts.test.ts` (resolution, version checks, URI validation and marker decoding) and the CLI's schema-check and replay tests.
