**Brief:** the owner, 2026-10-17: a Git-like CLI with every leg command under `baton leg`, and `baton leg log` showing a leg's logs. Each leg run's output is saved now, and the old command names go outright. B-22 specified it (baton#46).
**Spec:** `spec/BATON_SPEC.md` §11.3 (R-BTN-127), §8.5 (R-BTN-128), §8.4 (R-BTN-144: the one list of
what is masked), §14's rows; history, Migrations: renamed CLI commands.

### Why

R-BTN-127 and R-BTN-128 are specified. This ticket builds them, and moves every caller of the old names in the same release.

### What to build

1. **The tree.** Rebuild `cli/baton.mjs` as R-BTN-127's tree:
   - each command signs as its one role, with `-i` or `~/.config/baton/keys.json`;
   - each old name exits 2 with its "renamed:" line, kept until no caller uses it (history, Migrations);
   - an ambiguous ticket id lists its matches;
   - the leg default is running, then queued, then most recent;
   - the channel verbs work only inside a leg;
   - `help` covers every level, with nearest-name suggestions;
   - every read takes `--json`;
   - R-BTN-127's rows that later tickets fill in: `decision list` on the conditions route and
     `owner resolve` (B-56), `leg raise` (B-55), `leg await` (B-59).
2. **The archive.** In `src/runner`: read the pipes of a `process`-mode leg whether or not anyone is watching, mask R-BTN-144's closed credential set on the byte stream before framing, append to `baton-legs/<repository id>/<local ticket id>/<leg>/<run>-<claim id>.jsonl` with bounded retries and buffer, and report the pointers on heartbeat, `advance` and `end`. Only when the owners set `leg_logs: true`.
3. **The server.**
   - the `leg_logs` table and its pointer validation;
   - the `leg_logs` setting;
   - `GET …/tickets/{ticket}/legs/{leg}/runs`;
   - `GET /v1/stream`, signed by an owner or administrator key and closed on revocation;
   - `POST /v1/owner/{repository}/tickets/{ticket}/release`.
4. **`baton leg log`.**
   - finished runs from git, with the user's credentials;
   - `-f`, joining the archive and the stream on `seq`;
   - `--transcripts`;
   - session and attached runs as links;
   - the failure messages;
   - escapes and C0/C1 controls stripped on every printed path.
5. **The callers, in the same release.**
   - this repository's `README.md`, `scripts/`, tests and the runner's usage text;
   - the docs repository: `content/specs/BATON_DOCS_DEPLOYMENT.mdx` (docs' CI, `npx baton repo sync`, `baton course test`), `BATON_ROADMAP_PR_COURSE.mdx`, its skills and workflows that call `baton run`, `baton sync` or `baton test-course`.

### Do not

- Keep an alias for any old name.
- Store a log's bytes in Baton.

### Tests

- `npm test`, `npm run typecheck` and `npm run check:spec` green, and docs' `npm run verify` green.
