**Depends on:** none.

### What is open

B-314 made a running runner refresh its declared courses without a restart (#394). Round two of its review found three cases that still fail, each verified by the reviewer:

1. **A stale `origin/HEAD` is trusted.** A clean home tracking `origin/trunk`, after the remote switched its default branch from `main` to `trunk`, kept declaring v1: the runner rejected `trunk` as the wrong branch. Deleting the stale symref let it refresh at once. `src/runner/main.ts` still reads `refs/remotes/origin/HEAD` first. ([thread](https://github.com/immediately-run/baton/pull/394#discussion_r4668979360))
2. **Removing the last declaration holds only for the current reader.** Deleting `courses` while leaving `skills_version` and the course's directory makes the running reader return an empty list, but a fresh reader advertises the removed course again, even with `--course`. The shared-checkout exit-75 path can restart before the empty declaration is sent. ([thread](https://github.com/immediately-run/baton/pull/394#discussion_r4668979369))
3. **The spec still says courses are read at session start.** §8.1's heartbeat table describes `courses` as "read from the runner's checkout at session start"; it should cite rule 9 for when the list is read. ([thread](https://github.com/immediately-run/baton/pull/394#discussion_r4668979380))

### What to build

1. Resolve the registered default branch (or revalidate a cached `origin/HEAD` against the remote) before trusting the symref, and cover a stale symref as well as a missing one in S-BTN-313.
2. Make removal of the last explicit declaration hold across a restart: a fresh reader that finds `skills_version` but no `courses` field after an explicit declaration was seen does not fall back to directory discovery. Cover the fresh-reader case.
3. Amend §8.1's `courses` row to cite rule 9.

### Exit criteria

- S-BTN-313 covers a stale `origin/HEAD` and a fresh reader after the last declaration was removed; both pass.
- §8.1's row cites rule 9, with `npm run spec:index` run.
- `npm test` and `npm run typecheck` green.

### Trust

No new input. The runner reads its own checkout and its remote.

### Invariants

- Rule 9: the runner declares only courses its checkout holds, at the versions it holds.
