**Brief:** the owner, 2026-10-29, on BATON_SPEC §12.8's F1: "a domain that runs a branch's code is
a writer, with reviewers never executing branch code" — "Yes, this makes sense to me." The fifth
adversarial review found the standard courses contradict it: `src/runner/harness.ts` starts every
leg's agent with `opencode run --auto` or `claude --permission-mode bypassPermissions` in the
ticket's checkout, where opencode loads the branch's own configuration and plugins; the standard
`create-pr/review.md` tells the reviewer to run the tests; and B-110's `run-tests` leg runs the
branch's tests on an ordinary runner.

**Spec:** R-BTN-183 (a domain that runs a branch's code is a writer), R-BTN-181 (`std:ran@1`,
`std:checks@1`), R-BTN-131 (the standard courses); B-110, B-128 item 6.
**Depends on:** none.

### What to build

1. **Review legs are `reads_only: true`** in the standard courses (`create-pr`, `review-pr`,
   `branch`) under `landing: protected`: the stub gives the agent the diff and the changed files
   as data, from a tree it extracts (no working checkout of the branch, no `.git` hooks), and starts
   the agent with its configuration from the default branch's snapshot, in a directory holding no
   branch file the harness reads as configuration (`.claude/`, `.opencode/`, `opencode.json`,
   `AGENTS.md`, `CLAUDE.md`, `.mcp.json`).
2. **No command execution in a review leg's harness**: no `--auto`, no permission bypass; the
   harness's tool policy allows reading files only. The standard `review.md` drops "run the
   tests" and reads `std:checks@1` instead.
3. **Tests run in the trusted executor**: B-110's `run-tests` leg, under `protected`, becomes the
   executor's `std:checks@1` (B-128 item 6); on an ordinary runner it stays a fixer's feedback and
   counts as running the branch's code (`std:ran@1`).

### Tests

- A scenario (the next free S-BTN number): under `protected`, a review leg's agent command carries
  no `--auto` or permission bypass and its working directory holds no branch configuration file; a
  branch whose `.opencode/plugins/` writes a marker leaves no marker after a review leg.

### Exit criteria

- [ ] the scenario passes; `npm test` and `npm run typecheck` green
