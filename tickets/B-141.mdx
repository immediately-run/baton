**Brief:** the owner, 2026-10-29, on BATON_SPEC §12.8's F1: "a domain that runs a branch's code is
a writer, with reviewers never executing branch code" — "Yes, this makes sense to me." The fifth
adversarial review found the runner contradicts it: `src/runner/harness.ts` starts every leg's
agent with `opencode run --auto` or `claude --permission-mode bypassPermissions` in the ticket's
checkout, where opencode loads the branch's own configuration and plugins.

**Narrowed 2026-10-29.** The owner: "baton should ship courses that don't rely on fieldhouse's
specific architecture, and thus are simpler / aimed at less sophisticated users." The courses that
review without running branch code and run tests in a trusted executor are Fieldhouse's (FLDH-41).
This ticket keeps Baton's mechanism only; the standard courses and B-110 do not change.

**Spec:** R-BTN-183 (a domain that runs a branch's code is a writer; "Baton records this; the
deployment makes it true"), R-BTN-131 (the standard courses' scope).
**Depends on:** none.

### What to build

1. **A `reads_only` leg's workspace**: the stub gives the agent the diff and the changed files as
   data, from a tree it extracts (no working checkout of the branch, no `.git` hooks), in a
   directory holding no branch file a harness reads as configuration (`.claude/`, `.opencode/`,
   `opencode.json`, `AGENTS.md`, `CLAUDE.md`, `.mcp.json`); the agent's configuration comes from
   the default branch's snapshot.
2. **No command execution for a `reads_only` leg**: the harness starts the agent with no `--auto`
   and no permission bypass, and with a tool policy that allows reading files only.
3. Legs that are not `reads_only` run as today.

### Tests

- A scenario (the next free S-BTN number): a `reads_only` leg's agent command carries no `--auto`
  or permission bypass and its working directory holds no branch configuration file; a branch whose
  `.opencode/plugins/` writes a marker leaves no marker after a `reads_only` leg.

### Exit criteria

- [ ] the scenario passes; `npm test` and `npm run typecheck` green
