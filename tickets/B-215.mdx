`/sessions`"; Decision 1a in B-191, answered by the owner on 2026-11-09, makes them read-only and keeps export

Live claims 2 / 7, Alive workers 3 / 16, Live tickets 241 / 5,000, each with a bar) are `/state`;
the requests card is the day's count, since 600 a minute is a per-credential limit (R-BTN-135),
not the tenant's.

### What to build

1. **`/settings`** (`src/dashboard/screens/tenant/Settings.tsx`): `link_hosts` and
   `session_hosts` as lists, `check_app_id` as text, each with its one-line meaning (R-BTN-112,
   R-BTN-113, §12.7); `baton admin settings set [--link-hosts …] [--session-hosts …]
   [--check-app-id <id>]` as text.
2. **`/state`**: a banner when `frozen` or `sealed` (R-BTN-88) with what each means for writes;
   the mockup's cards from `admin.tenant` — live claims, alive runners, live tickets and
   repositories, each as "n / envelope" with a bar and the numbers as text; the day's requests
   and row writes as cards with no bar (no envelope applies); storage. `baton admin freeze`,
   `admin unfreeze`, `admin seal`, `admin export [--with-history]` and `admin import <file>` as
   text; no control, and no export link (Decision 1: the whole tenant's state is never behind a
   cookie).
3. **`/sessions`**: a `<table>` of the live sessions — role, key fingerprint, repositories (an
   owner's), bound at, last seen, client address, the caller's own marked "this session";
   `baton admin sessions revoke --all` as text.
4. **Phone.** Cards stack at 375 px.

### What not to do

- No control (Decision 1a); no export from the dashboard under any answer; no import.
- No envelope figure invented: a card without an envelope has no bar.

### Trust

- **Every value** is the reads' text through `Text`; client addresses and fingerprints as text;
  answered to an administrator's session only. Nothing is written.

### Invariants

- **Administrators only** (R-BTN-57, R-BTN-155); **read-only** (§11.4, Decision 1a).
- **The envelope is the operator's advice** (R-BTN-87); **text, never markup** (§12.3).

### Tests

Under `test/ui/` with fixtures: the banner appears for `frozen`; the cards draw each live count
against its envelope and the day's counts without a bar; `/sessions` marks the caller's own;
every command line matches R-BTN-127's tree; no control is drawn; a hostile client address is
text.

### Exit criteria

- [ ] The three screens built, read-only, usable on a local Baton for an administrator's session.
- [ ] The tests pass; `npm test`, `npm run typecheck`, `npm run check:wiki` and
      `npm run check:tickets` are green.
