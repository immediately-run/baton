**Depends on:** none.

### What is open

1. The runbook's step-1 policy block fails when followed literally: `baton owner policy show` prints the whole read, `policy diff` compares the file against its inner `.policy`, and `policy set` sends the file as the policy document, which the server refuses (`policy.repository: unknown field`). The drill passes only because it extracts `.policy` into a second file, so the page's claim that the drill runs every command as written does not hold ([thread](https://github.com/immediately-run/baton/pull/248#discussion_r4582131946)). Separately, B-125's own status note of 2026-11-24 strikes the "drop `machine` from `inputs.board`" step, which the page still carries.
2. The drill's stand-in worker (`worker.mjs` in `scripts/drill-compromise.sh`) exits 0 on any HTTP answer, so the ack, the end and the resume claim pass when refused, and a refused end lets the bar probe count a `one-claim-per-worker` refusal as the `barred-tag` proof ([thread](https://github.com/immediately-run/baton/pull/248#discussion_r4582131953)).
3. The runbook says a single claim can be stopped from the dashboard's Running view (Stop leg, R-BTN-119); no such view or control exists, so under pressure the operator finds only force-reap ([thread](https://github.com/immediately-run/baton/pull/248#discussion_r4582131957)).

### What to build

1. In `docs/runbooks/compromised-runner.mdx`, either write only the `.policy` object back to a second file and `diff`/`set` that (as the drill does), or, if `inputs.board` no longer governs a machine key's post on `main`, remove the block and say why; make the drill run exactly what the page prints.
2. Make `worker.mjs` exit non-zero on a status of 400 or more, and have the drill check the ack, end and final claim the way it already checks the initial claims; make the bar probe match `barred-tag` specifically.
3. Point the graceful stop at the control the current dashboard has for R-BTN-119's release (or the CLI's `leg stop`), and keep force-reap named as the fencing fallback.

### Exit criteria

- `scripts/drill-compromise.sh` runs every command block of the runbook verbatim and exits non-zero when any worker call is refused (checked with a forced refusal).
- `npm run check:wiki`, `npm test` and `npm run typecheck` green.

### Trust

The runbook is followed by a person during an incident and the drill uses throwaway keys on a scratch repository; no live credential is read or changed by this work.

### Invariants

- Every command the runbook prints is one the drill executes as printed.
- A refused call in the drill fails the drill.
