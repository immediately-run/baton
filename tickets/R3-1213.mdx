**Brief:** the Baton project.
**Spec:** `spec/BATON_SPEC.md` §9.2 (R-BTN-6, R-BTN-7, R-BTN-26, the three fence layers — the pre-push refusal covers ticket branches only), §8.1 (the sidecar, per harness: state file, spool, credentials), §9.9 (activities and their pairing; R-BTN-20), §2.1 R-BTN-32, §15 (S-BTN-2, -3, -4; G-BTN-15, -20, -25, -38); the spike `content/plans/baton/hook-spike.mdx` (R3-1210)
**Depends on:** R3-1212, R3-1210

### Requires

- none — the harness drives a scripted fake harness; no real Claude Code session is needed.

### Why

The client half of the lease: a sidecar that heartbeats while the harness lives, and fences
that stop a session that lost its lease from pushing, merging or writing status — through a
crashed sidecar, a laptop's sleep and a hung heartbeat. Tier: critical — the two-holder
invariant on the client side.

### What to build

1. `scripts/baton-sidecar.mjs` (state file, spool drain, heartbeat every 2 min with a 30 s
   timeout, process-group termination on fence, `--test-harness`).
2. `scripts/baton-now.mjs`, `scripts/baton-activity.mjs`, and `scripts/hooks/baton-*.mjs` for
   `SessionStart`, `SessionEnd`, `PreToolUse`, `PostToolUse`, `UserPromptSubmit`.
3. Those hooks registered in `.claude/settings.json` beside the existing ones.
4. A git `pre-push` hook (`scripts/hooks/pre-push`), installed by
   `scripts/setup/post-checkout.sh` into every workspace checkout.
5. `.claude/hooks/archive-transcript.sh` appends each pushed `(repo, path)` to the spool, or
   the parent's spool when `IR_BATON_PARENT` is set.

### Architecture — the decisions, named

- **Single writer.** Only the sidecar writes `~/.cache/immediately-run/baton/<session>.json`;
  everything else appends to `<session>.spool` (one JSON line, under 4 KB) or reads.
- **Every fence check calls one function**, `leaseState(stateFile, now)` in docs'
  `scripts/lib/baton.mjs` (the source vendored as baton's `src/shared/baton.mjs`, beside
  `batonNow`; R-BTN-26): lost when `now − last_ok ≥ lease_timeout − 4 min`, the flag is set, or
  the file is unreadable while the current branch is a ticket's branch; then the holder query.
- **`pre-push`** refuses only pushes to a ticket's branch (one matching a course's current or
  previous `branch_pattern`, R-BTN-51; docs' is `claude/{ticket}-*`) for a lost lease, and after
  cutover always asks the branch-holder query for them (§9.2 layer 3); it never refuses a
  `docs/main` push (a fenced session must leave its note).
- **Inert outside Baton.** A session with no machine key runs no sidecar (§8.1), and every
  hook exits 0 at once.
- Follow the spike's answers for deny, call ids and failure events; where it answered no, use
  the fallback it named.
- **Do not:** read any environment variable for time; block a tool call on the network
  (hooks only append); start a sidecar when `IR_BATON_PARENT` is set.

### Tests

- `scripts/lib/baton.test.mjs`: `leaseState` at the margin ± 1 s, with a missing file on a
  ticket's branch and off one.
- Integration with the fake harness: `S-BTN-2.silent-worker` (the dead session's push
  refused), `S-BTN-3.long-timeout` (SIGSTOP 11 h kept; 13 h reaped and its resumed push
  refused), `S-BTN-4.hung-worker` (force-reap; process group killed before the push), and the
  G-BTN-20 cases (crashed sidecar, wake from sleep, hung heartbeat), G-BTN-25 (network down,
  the spool keeps the entry), G-BTN-38 (an `IR_BATON_*`/`BATON_NOW` variable changes nothing).
