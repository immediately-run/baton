**Spec:** [BATON_SPEC §8.3](../spec/BATON_SPEC/08-runners.md#sec-8-3) ([R-BTN-123](../spec/BATON_SPEC/08-runners.md#sec-8-3), [R-BTN-72](../spec/BATON_SPEC/08-runners.md#sec-8-3), [R-BTN-107](../spec/BATON_SPEC/08-runners.md#sec-8-3)), [§8.4](../spec/BATON_SPEC/08-runners.md#sec-8-4) [R-BTN-119](../spec/BATON_SPEC/08-runners.md#sec-8-4) (stopping the
process group), [§7.4](../spec/BATON_SPEC/07-conditions.md#sec-7-4) [R-BTN-122](../spec/BATON_SPEC/07-conditions.md#sec-7-4) (the owners' `max_refreshes` ceiling).

### Why

R-BTN-123 is specified; this ticket builds it.

### What to build

1. Session adapters for `claude-code` and `opencode`.
2. `baton leg yield` and `refresh` in `baton leg status`.
3. `session` mode: replace the child session; `process` mode: abort `run` with reason `context`, call it again with `ctx.refresh`; `attached`: log once.
4. Neither a run nor an attempt; at most `max_refreshes` (under the owners' ceiling), then suspend at `from`.

### Tests

- S-BTN-88; G-BTN-108.
- `npm test`, `npm run typecheck` and `npm run check:spec` green.

### Exit criteria

- [ ] the scenarios above pass on both hosts, with their traces replayed through the model where they touch the core
- [ ] merged under the review gate
