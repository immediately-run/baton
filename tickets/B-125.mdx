**Brief:** the owner, 2026-10-27: "Baton as currently designed is completely unprotected against
scenarios where a runner is compromised (and this will happen sooner or later)." The security
model (`docs/security-model.mdx`, hardening option 3) ranks a written kill switch among the
cheapest measures: today revocation is improvised.

**Spec:** R-BTN-67 (owner bars), R-BTN-58 (grants and revocation), R-BTN-12 (holds), §12.2
(destructive actions), R-BTN-85 (discrepancies); `docs/security-model.mdx`.
**Depends on:** none.

### What to write

`docs/runbooks/compromised-runner.mdx`, a runbook a person follows under pressure, in order:

1. **Stop the fleet's hands.** An owner bar on every grant of the affected homes (one command
   per repository, listed), so nothing new is claimed; then `release` every active claim. State
   what keeps running (a leg mid-step) and how long until it stops.
2. **Cut the credentials.** Revoke the runner keys (`baton owner grant revoke`), the GitHub
   identity's SSH keys and `gh` tokens (the GitHub settings pages, named), and the slot's
   gateway virtual keys. Say which of these an agent may do and which a human must (Fieldhouse's
   fourth practice: credentials never enter an agent's context).
3. **Find what changed.** Commands that list, since a given time, every push to each home and
   output repository by the affected identity, every change to `.baton/`, goals, workflows and
   ticket frontmatter, every verdict and merge it made, and Baton's `discrepancy` and
   `foreign-write` events.
4. **Undo and resume.** Revert the identified commits, rotate any Actions secret a pushed
   workflow could have read, re-mint keys, lift the bars.
5. **Record it** in `docs/lessons.mdx`.

**After the adversarial review** (2026-10-27, `docs/security-model.mdx` *Review*):

- **The runbook starts with the key, not the identity** (finding 18): revoke the compromised
  runner key, set `machine_sync: false` (B-137), then bar and revoke as written. It covers a
  compromised server or Cloudflare account too (B-135): rotate the GitHub App key, the webhook
  secrets and the administrator keys, and redeploy from a known commit.

### Tests

- A drill, run once on a scratch repository: every command in the runbook executes as written
  against a local Baton and a test GitHub repository, scripted as `scripts/drill-compromise.sh`.

### Exit criteria

- [ ] the runbook merged and linked from `docs/security-model.mdx`
- [ ] the drill script passes
