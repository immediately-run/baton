**Brief:** the owner, 2026-10-17 (B-1, baton#43). docs and `roadmap-pr` are Baton's labelled
reference deployment, so they should use what the course schema adds once Baton serves it.
**Spec:** `spec/BATON_SPEC.md` §8.3 (R-BTN-106 `no_chain_from`, R-BTN-123 fresh context), §5.6
(R-BTN-121), §7.1 (R-BTN-160: declared condition types, `retryable`, `LegError(type, …)`), §7.4
(R-BTN-122), §6.2 (R-BTN-126: a provider at capacity is a blocked end); history, Migrations: the
`ROLES` window; docs' `BATON_ROADMAP_PR_COURSE` and `BATON_DOCS_DEPLOYMENT`.
**Depends on:** B-2 (done), B-10 (capability types), B-11 (retries per leg), B-12 (fresh
context), B-55 (declared condition types and typed `LegError`).

### Requires

A sibling docs checkout.

### Why

`roadmap-pr`, the course docs runs, still keeps its roles in the vendored `vocabulary.mjs`,
counts retries per ticket, and leaves the independence of `review` to convention.

### What to build

1. **Capability types.** Declare `roadmap-pr`'s capability types and roles in its course file
   (`capability_types`, `capability_roles`), which takes it out of the `ROLES` window; once no
   registered course reads through `ROLES`, retire it from docs' `vocabulary.mjs` and run
   `npm run vendor` in baton.
2. **Independence.** Give `review` a `no_chain_from: ["implement", "fix"]`, and set the docs
   repository's `required_independence` owner setting to match.
3. **Conditions and retries.** Declare the course's `interrupt` condition types in its
   `conditions` with `retryable` (for example `merge-conflict` `false`, `flaky-test` `true`); a
   provider's capacity reached is a blocked end, not a condition type (R-BTN-126). Give the
   agent legs `retry` policies within the owners' bounds, and throw `LegError(type, message)`
   from the leg scripts. Once B-66 ships, docs may bind `hitl` and `warning` in its
   `.baton/baton.json` (R-BTN-161); that is optional here.
4. **Fresh context.** Set `max_context` on `implement` and `fix`, and have their scripts report
   context use with `baton leg yield --context`.
5. **Docs.** Amend `BATON_ROADMAP_PR_COURSE` and `BATON_DOCS_DEPLOYMENT` to match, each with a
   dated note.

### Do not

- Put any of this in Baton's core (R-BTN-50): it is course data.
- Declare `error_types` or a per-leg `non_retryable`: the validator refuses both.

### Tests

- `baton course test` passes on docs' course, with no cut-back warnings that are not intended.
- docs' `npm run verify` is green.
- A shadow run shows `review` refused to the key that ran `implement`.

### Exit criteria

- [ ] the course file and leg scripts use the fields above, merged in docs under the review gate
- [ ] `ROLES` retired from the vendored library
