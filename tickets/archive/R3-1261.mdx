### Requires

### Why

The owner set the runner API's prefix to `/v1/runner` (2026-10-15): the routes a worker's sidecar
and runner call are the runner API. Every later server item (R3-1231, R3-1232, R3-1251, R3-1260)
writes routes under the prefix, so the move lands first and alone, where a reviewer can check it
changes nothing else. Tier: judgement — two repositories and a wire change.

### What to build

1. baton: every route under `/v1/worker/` moves to `/v1/runner/` — the front's principal check
   (`src/core/front.ts`), the core's router (`src/core/baton.ts`), and every message, refusal and
   comment that names a path; the tests and README follow.
2. docs: `scripts/baton-worker.mjs`, `scripts/claim.sh` (its self-test stubs) and
   `scripts/baton-client.test.mjs` call the new paths; `skills_version` is bumped (a protocol file
   changes, `check-baton`).

### Architecture — the decisions, named

- **No alias**: the old prefix is not served, because nothing is deployed (R3-1208 is unrun) and
  no client outside these two repositories exists.
- **The prefix only**: route names, request and response shapes, refusal codes, the `worker`
  concept (tables, `worker_id`, `/v1/ui/` views) and the principal header stay as they are.
- **Do not**: change any rule, response or refusal other than a path; edit archived items or the
  spec's history rows (§15's earlier rows, the review record).

### Tests

- Every existing unit and integration test passes on both hosts with only paths changed.
- `test/integration/S-BTN-31.both-hosts.test.ts` (or a unit test): a request to the old prefix is
  `not-found` on both hosts.
- docs `node --test scripts/baton-client.test.mjs` and `bash scripts/claim.sh --self-test` pass.
- Scenarios: none new.

- [x] `git grep -nE 'v1\\?/worker' -- src test ':!test/integration/S-BTN-31.both-hosts.test.ts'` returns nothing in baton, nor `-- scripts` in docs — the pattern also catches a regex's escaped `\/v1\/worker`, and S-BTN-31 must name the old prefix to show it is not served *(amended 2026-10-15 while building)* — evidence: empty on baton main 743df7b and docs scripts
