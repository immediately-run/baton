**Brief:** `fieldhouse/spec/FIELDHOUSE_SPEC.md` (read at fieldhouse's `main` on 2026-11-20)
still reads Baton's spec as it was before [PR #299](https://github.com/immediately-run/baton/pull/299).
Line 54 sets `executor.builtin: refused`, a knob Baton's §12.8 no longer has. Lines 458–461 anchor
four assumptions at `baton/spec/BATON_SPEC.md`, and line 5 names the same file; that file is the
generated index and contains none of the four grep tokens, which are in the section files. Seven
lines call a role the "trusted executor" (118, 120, 543, 551, 555, 888, 977), which collides
with Baton's executor (the runner's module, R-BTN-107) and its `trusted-runner` role. Seventeen
lines cite R-BTN-182, R-BTN-183 or R-BTN-184 for behaviour Baton now states only on
`spec/proposals/security.md`. The findings are in
[the review](../../docs/review/spec-simplification-review-2026-11-19.mdx), section 5 and *Left for
tickets*, item 5. Fieldhouse's spec does not cite R-BTN-192; the review's list was wrong on that
one.

## Plan

The work is one pull request in `immediately-run/fieldhouse`, by that repository's own rules
(its `CLAUDE.md`, its spec history, `npm run check:wiki` there). Nothing in `baton` changes
except this ticket's status.

1. **`executor.builtin`.** In R-FH-3's *Two knobs no guarantee holds* (lines 53–57 and the
   sentence that follows on what the second knob refuses), keep `repos.unlisted: none` and
   delete `executor.builtin: refused` with its explanation; the heading becomes one knob.
   Fieldhouse's history entries that mention the knob (`FIELDHOUSE_SPEC_HISTORY.md` lines 367,
   432, 499) stay as history; the new entry says Baton removed it.
2. **Anchors.** In §3's *Depends-on-today* table, change the anchor of each row to the section
   file that holds its token:

   | Token | New anchor |

### Trust

This ticket's `repos:` names `fieldhouse` alone, and the work is a spec edit there. It changes
no credential, grant, owner setting, CI workflow or deploy in either repository. Fieldhouse's
spec is standing guidance that agents read (reach 3), so the change lands only through a pull
request its owner merges. The line numbers and quotations above were read from a local checkout
and are claims: the leg re-reads the file at fieldhouse's head before editing. Step 4 must not
loosen anything: it marks Baton behaviour as unbuilt, which makes Fieldhouse's own enforcement
(R-FH-91's forge gate, its weekly audit) the only enforcement, and the PR says so in each place.
