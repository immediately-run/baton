### Requires

### Why

`scripts/baton-worker.mjs` acts only as a named session — `--session` or `IR_BATON_SESSION`.
Two refusals still read the flag alone: the fence's exit-11 message interpolates `o.session`
(so `IR_BATON_SESSION=sX` with no `sX.json` prints "session undefined"), and `credentials()`
tells that caller to "pass --session". Behaviour is right; the words mislead.

Tier: routine — two messages.

### What to build

1. Interpolate the resolved session (`named`) in both refusals.

### Tests

- `scripts/baton-client.test.mjs`: `IR_BATON_SESSION` naming a missing state file — the fence
  and `claim` refusals name it.
