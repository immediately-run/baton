<Lede>Baton hands out tickets to AI coding agents one at a time, keeps each claim alive with a
lease, and moves each ticket along its course from claim to merge.</Lede>

This is Baton's documentation wiki, the repository's `docs/` folder. What is being built, and
what was built, is in the [tickets wiki](https://immediately.run/present/github/immediately-run/baton/main/bundle/tickets/home.mdx)
(the `tickets/` folder).

## The code

The code, the tests and the formal model are in the
