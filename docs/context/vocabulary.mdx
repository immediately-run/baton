<Lede>These are core's words. A word not on this page — pull request, review, model, provider —
belongs to a course, and Baton passes it through unread.</Lede>

**Repository.** A git repository registered with Baton. Its `.baton/` folder describes its
courses; its sync tells Baton where every ticket is.

**Home, code repository.** Every ticket lives in one repository, its **home**, which holds its
board, its courses and its owners. The repositories a ticket's work changes are its **code
repositories**: the home's owners list them in `code_repos`, and they hold no tickets of their
own. What a home covers is its owners' choice; Baton has no word for it.

**Ticket.** A unit of work, filed in git. Baton knows its id, course, tier and requirements,
never its body.

**Course.** The state machine a ticket follows: **stations** it rests at and **legs** it runs
between them. Defined in `course.json`; changed by a commit.

**Station.** A place a ticket rests between legs (`filed`, `reviewed`, `merged`). An **end
station** finishes the ticket.

**Leg.** One edge of the course (`implement`, `review`, `merge`). A leg is **ready** or
**waiting** on something named.

**Path.** The legs a ticket has run and the stations they reached, read from git.

**Worker.** An agent session on a machine, identified by its key. It declares capabilities,
a tier ceiling, tags and the courses it can run.

**Holding, ontology, derived capability.** What a worker declares (a key's name, an installed
tool) are its holdings; a repository's ontology derives further capabilities from them, so a leg
can require an ability while workers declare only what they hold.

**Route choice.** A question a repository attaches to a leg for advice — which model, through
which key — that the ontology answers from the worker's holdings and the instruments' readings.
Advice, never a gate; not a choice station, which is a course's race between legs.

**Claim.** A worker's lease on one ticket. It runs one or more legs and ends **done**,
**suspended** at a station, or **released**.

**Lease, heartbeat, reap, fence.** A claim lives while its worker heartbeats. A silent worker
is **reaped** at its lease; a **fence** stops a revived worker from writing.

**Gate.** A rule Baton enforces for safety: one holder, capabilities, tier, grants, barred
tags. Everything else is **advice**.

**Tag, barred tag.** Short strings a course gives workers (`family:glm`). A leg can bar tags,
so some workers may not run it.

**Owner bar, required bar.** Limits a repository's owners set in Baton that agents cannot
change: tags barred across courses, and bars every leg must carry.

**Sync, snapshot, observation.** The repository's sync reads git and posts a **snapshot**.
Each carries an **observation** number, so a stale reading never overrules a newer one.

**Confirmation.** A completion counts once a later snapshot shows it in git.

**Hand-off.** The document a suspended or released claim leaves for the next claimant.

**Hold, expedite.** An operator's overrides: stop a ticket being offered, or put it first.

**Block, decision.** Why a ticket cannot move — another ticket, a missing capability, an
outside resource — and the questions only a person can answer.

**Administrator, owner, grant.** Administrators run the instance; each repository's owners
grant worker keys access to it.

**Policy, preset, guarantee, floor.** A repository's policy is the one versioned document of
every rule about authority and trust — who lands on which refs, who approves what, whose
attestations count — held in Baton, never in git. A preset (`cooperative`, `protected`) is a set
of values an owner applies and then tunes. A guarantee is a named condition over the policy; a
floor is a set of guarantees Baton refuses to let any change break (§12.8).

**Attestation, reading.** A typed statement Baton records — a review, a check run, a human's
approval, a provider's remaining funds — about a ticket or commit, or about a resource instance (a
**reading**); git never supplies one. A leg's course says which attestations it requires, from
which writers, and whether a missing one blocks the leg or only steers advice.

**Outbox, courier.** Every effect Baton intends outside itself — a git write, a check run — is an
outbox entry; a courier, a key whose host holds the credential the effect needs, delivers it, and
Baton confirms it by reading it back.

**Trusted runner.** A runner that claims only legs marked `trusted`, runs no repository code, and
acts on attestations alone; the merge runner is the first.

**Protected path.** A path whose changes a trusted runner never merges alone: a computed floor
(`.baton/`, workflows, agent configuration, tickets) plus the owners' own; control paths land
only by a human.

**Human-only key.** A key used for nothing else and kept out of every agent's reach; only it
satisfies a human gate.
